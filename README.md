# Escale Créteil

Un guide de séjour chaleureux en français, anglais, espagnol et arabe.

Arrivée autonome, Wi-Fi, bonnes adresses, itinéraires, règles de la maison, checklist de départ et contact WhatsApp/SMS.

Site statique : index.html, style.css, app.js et assets/. Publication GitHub Pages depuis main, dossier racine.

Les photos officielles restent attribuées à leurs exploitants. Les crédits des images se trouvent dans assets/photo-credits.json.
